# Contributing / 贡献说明

This repository is public; no GitHub Release has been created. Use an issue or pull request for corrections. Do not publish or mirror private material as part of a contribution.

## Code and documentation
Submit only original material you have the right to license. Identify the original repository-level code/documentation you intend to provide under the [MIT License](LICENSE), and retain relevant source attributions. Third-party text remains subject to its own rights.

## Pet assets
Each pet contribution must state its contributor, source character/work, reference-source provenance, permitted uses, and excluded third-party rights in its own `LICENSE.md`. Fan-character assets must not be presented as wholly MIT-licensed or cleared by a blanket Creative Commons license.

For changes to an existing pet:
- Preserve its `NOTICE.txt`, `LICENSE.md`, source information, and attribution.
- Identify your modifications and any new input/reference material.
- Do not claim rights you do not hold or that the repository's notice grants third-party permission.
- Keep the extracted folder and standalone ZIP consistent and refresh manifest/checksums after changes.
- Explain any structural checks, retained warnings, and runtime tests actually performed.

A contribution does not itself authorize a separate release or gallery submission. A rights concern or removal request can be raised in [Issues](https://github.com/tyxkk2/inori-codex-pets/issues) as a public contact route.
