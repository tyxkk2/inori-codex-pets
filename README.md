## English
This review bundle contains five completed unofficial Inori Yuzuriha fan-art pets: Q/chibi goldfish, school tracksuit and red jacket, plus standard-proportion school tracksuit and red jacket.

Open **PREVIEW.html** for the existing GIF previews. The five independent archives are in packages/. Each has pet.json, spritesheet.png and NOTICE.txt at its root. The outer bundle is for review and archiving, not a single-pet import archive.

All five sheets retain their original 1536×2288 RGBA PNG bytes: an 8×11 grid with 192×208 cells, nine animation rows and sixteen directional poses in the final two rows. Packaging did not generate, redraw, crop, rescale or re-encode the PNGs/GIFs.

Read INSTALL.md for source-verified Petdex Desktop local loading. Read VALIDATION.md for its limitations. A current ChatGPT-native ZIP import interface has not been verified.

Public scope, attribution/contact details, source-reference review and licensing remain undecided. No public repository/gallery submission was made by preparing this bundle. It grants no new rights. Do not label these assets official, cleared for underlying character rights, MIT-licensed, or CC0.
